# Abdurazaq Gorja · Portfolio

Portfolio of Abdurazaq Gorja, filmmaker and creative director in Addis Ababa and founder of ZAQ Media.
Hosted on GitHub Pages.

A single static page: `index.html` plus the `media` folder. No build step.

- Videos play from Vimeo in an on-page player. Each video's Vimeo privacy must allow embedding on the portfolio's address.
- To add or change a video, edit the `const all = [ ... ]` list in `index.html`. `img` is the still in `media/`, `id` is the Vimeo number.
- Publishing steps are in [DEPLOY.md](DEPLOY.md).
